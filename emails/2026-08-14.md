### Doltgres and DoltLite on DoltHub

One of the big changes here at DoltHub in 2026 is [the addition of new database flavors to the Dolt lineup](https://www.dolthub.com/blog/2026-07-16-dolt-in-4-flavors/). DoltHub is now the version-controlled database company! [MySQL](https://www.doltdb.com), [Postgres](https://www.doltgres.com), [SQLite](https://doltlite.com), or [Mongo](https://github.com/dolthub/dumbodb). Your choice.

These databases all work, with Dolt and [Doltgres both being production-ready](https://www.dolthub.com/blog/2026-08-06-doltgres-1-0/). But we have a bit of catching up to do with the surrounding services. This week, we announced [remote-only support for Doltgres and DoltLite on DoltHub](https://www.dolthub.com/blog/2026-08-07-dolthub-supports-doltlite-and-doltgres/). You can create Doltgres and DoltLite databases and push, pull, and clone them, but Pull Requests and the built-in SQL workbench are not yet supported. We're on it.

### Prolly Tree Visualizer

Can I interest you in a visit to https://www.prollytree.com? 

The [Prolly Tree data structure](https://www.dolthub.com/docs/architecture/storage-engine/prolly-tree/) that makes all the Dolts possible now has [its own visualizer](https://www.dolthub.com/blog/2026-08-10-prolly-tree-visualizer/) inspired by [btree.app](https://btree.app/). The visualizer is a great way to understand Prolly Tree's b-tree like seek performance, fast diff, structural sharing, and history independence properties. These properties make version control of structured data possible at scale. 

Built on [DoltLite's](https://github.com/dolthub/doltlite) Web Assembly (WASM) build so it runs entirely in your browser.

### Doltgres Performance

[Doltgres is as fast as MySQL is slow](https://www.dolthub.com/blog/2026-08-13-doltgres-as-fast-as-mysql-is-slow/). In other words, [MySQL is 2.6X slower than Postgres on sysbench](https://www.dolthub.com/blog/2024-07-16-mysql-postgres-sysbench-latency/). Doltgres is 2.6X slower than Postgres on sysbench. We'll keep optimizing performance of all Dolt flavors.
