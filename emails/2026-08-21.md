### Agentic Engineering

[Vibe coding](https://www.dolthub.com/blog/2026-03-26-vibe-code-vs-trad-code/) has been rebranded [agentic engineering](https://simonwillison.net/guides/agentic-engineering-patterns/what-is-agentic-engineering/)! Even so, where is all the new, cool software? All I'm seeing is rust ports. We here at DoltHub are doing our part with two novel, agent-engineered version-controlled databases, [DoltLite](https://github.com/dolthub/doltlite) and [Dumbo](https://github.com/dolthub/dumbodb), products we've wanted to build for years.

[My latest blog article](https://www.dolthub.com/blog/2026-08-17-top-5-agent-engineered-open-source-projects/) tries to identify the top 5 agent-engineered open source projects that aren't affiliated with Dolt. This is all in service of removing the agent-engineered stigma.

### Hosted Dolt Rest API

Here at DoltHub, we firmly believe agents will outnumber humans as users of our products very soon. Agents seem to prefer programmatic access like APIs or CLIs. In service of our new agent customers, a month ago we [launched DoltHub API v2](https://www.dolthub.com/blog/2026-07-09-dolthub-api-v2/) and this week we [launched a Hosted Dolt API](https://www.dolthub.com/blog/2026-08-20-hosted-rest-api/) built to the same standard. Expect CLIs that use these new APIs in the next few weeks.
