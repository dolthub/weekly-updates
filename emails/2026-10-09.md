### How Remotes Work

[Eric](https://www.dolthub.com/team#eric) has been riding shotgun for me on [DoltLite](https://github.com/dolthub/doltlite) for the past couple months. He's been tasked with making DoltLite work on DoltHub. Right now, you can [clone, push, pull, and fetch DoltLite databases](https://www.dolthub.com/blog/2026-08-07-dolthub-supports-doltlite-and-doltgres/) but none of the other functionality works, like Pull Requests. DoltLite is a completely different, single file storage format so all the DoltHub backend machinery to read it and write to it needs to be built. This forced Eric to deeply understand Dolt remotes and he chose to [share that knowledge with you](https://www.dolthub.com/blog/2026-10-08-how-dolt-remotes-work/).
